# 🍽️ Zomato Analytics
## 📌 Overview
This project analyzes Zomato’s global restaurant dataset to uncover insights into restaurant distribution, pricing behavior, customer preferences, and platform growth trends across countries and cities. The analysis demonstrates how data analytics can support strategic decision-making for marketplace platforms.

## 🎯 Business Objectives
1. Understand restaurant distribution and growth across cities and countries.
2. Analyze pricing patterns and customer ratings.
3. Identify factors influencing restaurant performance and engagement.
4. Build KPI-driven dashboards for decision support.

## 📂 Dataset Overview
Restaurant-level data collected from Zomato across multiple countries, including:
Location & operational attributes,
Pricing and cost details,
Customer ratings and votes,
Cuisine types and
Restaurant opening dates

## 🛠️ Tools & Technologies
Excel – Data validation, calendar table creation

MySQL – SQL queries and KPI aggregation

Power BI & Tableau – Interactive dashboards and visual storytelling

## 📊 Key Insights

1. India and the USA dominate restaurant listings on Zomato.
2. Mid-range restaurants form the majority, while fine-dine outlets achieve higher ratings.
3. Restaurants offering online delivery and table booking show stronger engagement.
4. World and multi-cuisine restaurants consistently receive higher ratings.
5. Restaurant openings peaked between 2013–2018, indicating rapid platform expansion.

## 💡 Business Recommendations
1. Increase adoption of online delivery and table booking features.
2. Improve service quality to raise the global average rating.
3. Promote high-performing cuisines such as World and Multi-cuisine.
4. Expand into underrepresented but high-growth cities.
5. Leverage seasonal opening trends for marketing and partnerships.

## 📈 Project Outcomes
1. Built a calendar table for time-based analysis.
2. Standardized pricing across countries using USD conversion.
3. Developed KPI cards and interactive dashboards.
4. Created end-to-end analytics workflow from data preparation to visualization.
